# Contributing to the Project

If you find a bug or unexpected behavoir, please let us know:
1. Go to the **Issues** tab at the top of the repository.
2. Click **New Issue**.
3. Select and fill out the **Bug Report** template with as much details as possible, including steps to reproduce the issue.

# How to Suggest a New Feature

We are always open to new ideas, especially those related to **math and kinematics**!

To suggest a feature:
1. Open a new **Issue**
2. Clearly describe the problem you want to slove or the feature you want to add.
3. If your idea involves kinematics formulas or mathematical models, please include brief explanations, formulas, or links to relevant academic papers if available.

## Step-by-Step Pull Request Process

If you have never used Git before, don't worry! Here is a simple guide to submitting your changes:

1. **Fork** the repository by clicking the **Fork** button in the top right corner of this page.
2. **Clone** your forked repository to your local machine:
   `git clone https://github.com/YOUR_USERNAME/REPOSITORY_NAME.git`
3. **Create a new branch** for your work. Keep the name short and descriptive:
   `git checkout -b feature-or-fix-name`
4. Make your changes and **commit** them with a clear message:
   `git add .`
   `git commit -m "Briefly describe what you changed"`
5. **Push** your branch to your GitHub account:
   `git push origin feature-or-fix-name`
6. Go to the original repository. GitHub will show a prompt to create a **Pull Request (PR)**. Click **Compare & pull request**, fill out the description, and submit it for review!

## Coding Style

To keep the codebase clean and maintainable, please follow these language conventions:
* **JavaScript**: Use clean Vanilla JS (ES6+ standard).
* **Python**: Follow standard Python conventions (PEP 8 guide).
* **C++**: Follow standard C++ conventions (such as the Google C++ Style Guide).
